# Статус проверки коннектора

Дата: 2026-10-02

## Общая архитектура

В одном дереве исходников находятся общее модульное ядро и платформенные адаптеры:

- `Platform/Modx2Platform.php`
- `Platform/Modx3Platform.php`
- `Registry/ToolRegistry.php`
- `Legacy/LegacyActionAdapter.php`
- модульные `Tools/`
- общая точка входа `endpoint/api.common.php`

Модульный реестр полностью покрывает публичный контракт: 74 действия только для чтения и 108 изменяющих действий, всего **182/182**. Прежний диспетчер сохранён только как слой совместимости и эталон для проверок; обычные запросы обрабатываются модульной средой выполнения.

## Готовность 1.1.0 к релизу

Версия 1.1.0 — первая общая линия исходников для MODX 2 и MODX 3. MODX 3.2.4-pl прошёл полную проверку на работающем тестовом сайте. Для MODX 2 проходят подготовка релизной сборки и статическая проверка совместимости с PHP; перед публикацией 1.1.0 как окончательного стабильного релиза требуется отдельная проверка релизной сборки на реальной установке MODX 2.

## Текущее модульное покрытие изменяющих операций

Модульная среда выполнения содержит все 108 изменяющих действий.

<!-- MUTATION_MIGRATION_COVERAGE: 108/108 -->

Первым блоком изменяющих операций стал прямой слой штатных процессоров MODX для прав доступа, контекстов, пространств имён и словарей. Эти действия выполняются через `ProcessorMutationTool` и `MutationProcessorCatalog` вместо прежнего диспетчера. Перенос завершён: все 108 изменяющих действий зарегистрированы в модульной среде выполнения, поэтому все **182** серверных действия имеют модульную реализацию.

2 октября 2026 года текущий модульный реестр повторно проверен на отдельном тестовом сайте MODX 3.2.4-pl с помощью `_build/test.live-modular-parity.php`. Каждое действие выполнялось один раз через модульный реестр и один раз через тот же экземпляр коннектора с отключённой модульной средой выполнения (`modularRuntime`). Результаты совпали, включая ожидаемое поведение при ошибках.

Чтение файловой системы через источник файлов на тестовом сайте остаётся отключено настройкой `modxmcp.allow_root_filesystem_read=0`. Проверка подтверждает одинаковый запрет безопасности по обоим путям и не ослабляет настройку ради теста. Группы возможностей, отключённые в постоянных настройках, включаются только в памяти процесса проверки, поэтому после теста сайт не остаётся с расширенными правами.

- Совпадение изменяющей операции VersionX: **пройдено** для безопасного сценария `confirm=true` при отсутствии версии; реальный контент не изменялся.
- Совпадение изменяющих операций miniShop2: **пройдено**, 12/12 действий; сценарии создания откатывались транзакционно, реальные заказы и товары не изменялись.
- Финальная проверка массовых изменений: **пройдена**. `bulk_resources` и `replace_across` совпадают с прежней реализацией и в режиме предварительного просмотра, и при реальной записи во временные объекты.
- Полная проверка на работающем сайте: **пройдена**. Все 14 наборов проверок совпадения поведения завершились с кодом 0 на финальной модульной среде выполнения.
- Два глобально разрушительных действия не запускались на работающем сайте: `empty_recycle_bin` и `regenerate_token`. Оба покрыты модульной регистрацией, статическими проверками контракта и проверкой эквивалентности прежней реализации.
- Совпадение изменяющих операций управления пакетами: **пройдено**, 5/5 действий; установка и удаление пакетов проверялись только на неразрушительных сценариях.
- Совпадение изменяющих операций MIGX: **пройдено**, 3/3 действий с транзакционным откатом.
- Поведение VirtualPage при отсутствии компонента: **пройдено**, 10/10 действий совпадают с прежней реализацией. Полный положительный цикл необходимо дополнительно проверить на тестовом сайте с установленным VirtualPage.
- Изменяющие операции с элементами: **пройдены** для всех 7 поддерживаемых типов. Проверены создание, изменение, предварительное удаление и фактическое удаление.
- Работа элементов с файлами: **пройдена** для `make_static` и редактирования строк в базе данных и статических файлах у чанков, сниппетов, шаблонов и плагинов; тестовые файлы удалены.
- Получение списка и отдельного элемента (`list/get`): **пройдено** для всех 7 поддерживаемых типов.
- Просмотр элементов (`view`): **пройден** для всех 4 типов, поддерживающих эту операцию.
- Ограничение безопасности при отключённом источнике файлов, работающем с файловой системой: **пройдено** во всей серии проверок совпадения поведения.
