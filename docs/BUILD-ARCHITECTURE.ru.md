# Архитектура сборки

Из одного дерева исходников коннектора собираются два варианта релиза:

- **MODX Revolution 2.8.x** — идентификатор платформы `modx2`, транспортный пакет `modxmcp-<version>-pl.transport.zip`;
- **MODX Revolution 3.x** — идентификатор платформы `modx3`, транспортный пакет `modx3mcp-<version>-pl.transport.zip`.

Обе сборки используют один MCP-клиент, один публичный контракт действий и одну модульную среду выполнения из `core/components/modxmcp/src/`.

Общая кодовая база включает:

- `core/components/modxmcp/src/`;
- классы инструментов, реестр, дополнительные модули, логику точки входа API и документацию;
- общие ресурсы интерфейса и логику менеджера там, где MODX 2 и MODX 3 работают одинаково.

Платформенные файлы сборки и загрузки находятся в `_build/platform/<platform>/`. Скрипт `_build/prepare-release.py` создаёт чистое подготовительное дерево для выбранной платформы и накладывает только нужный платформенный слой.

Архитектура специально избегает проверок версии, разбросанных по прикладным классам инструментов, например `if (MODX_VERSION...)`. Различия MODX 2 и MODX 3 изолированы на границе загрузки и сборки и за интерфейсом `PlatformInterface`.

## Подготовка дерева релизной сборки

MODX 3:

```bash
python3 _build/prepare-release.py --platform modx3 --output /tmp/modxmcp-modx3
```

MODX 2:

```bash
python3 _build/prepare-release.py --platform modx2 --output /tmp/modxmcp-modx2
```

Каждый транспортный пакет нужно собирать на установке MODX той же основной версии.

## Статус версии 1.1.0

Версия 1.1.0 — первая общая линия исходников для MODX 2 и MODX 3.

- модульное покрытие действий: **182/182**;
- MODX 3.2.4-pl: полная проверка на работающем тестовом сайте завершена;
- совместимость процессоров MODX 3 проверяется на 3.2.2-pl, 3.2.4-pl и актуальной ветке 3.x;
- MODX 2.8.9-pl: отдельная проверка транспортного пакета и основная серия проверок на работающем сайте завершены;
- проверки обеих платформ завершены; перед публикацией остаются финальные артефакты и контрольные суммы, тег и релиз GitHub.
